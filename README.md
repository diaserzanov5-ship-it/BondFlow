# BondFlow

BondFlow — хакатонный прототип корпоративных действий по токенизированным облигациям: событие купона, список тестовых прав на выплату и проверяемый перевод тестовых токенов в Solana.

## Текущий статус

- Этап 1: структура веб-приложения и Solana-программы создана; production-сборка интерфейса проходит.
- Этап 2: Anchor-программа описывает событие, права, пополнение пула и однократное получение выплаты. Исходник пока не собран: на текущей Windows-среде нет WSL, Rust, Solana CLI и Anchor CLI.
- Этап 3: собран интерфейс демо-режима, подключение Phantom и создание локальных черновиков с SHA-256 хешем; интерфейс пока не отправляет транзакции в программу.
- Этапы 4–5: Devnet-развёртывание, проверка транзакций и сценарий демонстрации ждут установки Solana toolchain через WSL и интеграции клиента с собранной программой.

Все данные и обозначения `TEST-KZT` демонстрационные. Проект не подключён к данным KASE, не использует реальные ценные бумаги и не производит реальные выплаты.

## Запуск веб-интерфейса

```powershell
cd apps/web
npm install
npm run dev
```

## Структура

- `apps/web` — интерфейс оператора и держателя.
- `programs/bondflow` — Anchor-программа для Devnet-прототипа.
- `Anchor.toml` — настройки Anchor для локальной разработки и Devnet.

## Смарт-контракт

Инструкции программы:

1. `create_action` — создать событие и тестовое хранилище токенов.
2. `register_entitlement` — записать право кошелька на сумму купона.
3. `fund_action` — пополнить пул через Token Program.
4. `open_claims` — открыть получение, когда тестового баланса хватает на все права.
5. `claim` — перевести держателю положенную сумму и создать уникальную запись получения.

В сети фиксируется хеш описания события; документы и персональные данные в программу не помещаются.
